# AirStats 简体中文版

完整的中文版介绍、下载与安装说明请见 [项目首页的简体中文部分](README.md#简体中文)。

本项目基于 [AirStats](https://github.com/byrencheema/airstats) 1.6，是非官方汉化适配。当前版本 `v1.6-zh.2` 支持在“通用 → 语言”选择简体中文或 English，退出并重新打开后生效；中文仍有少量内容为英文。它还提供菜单栏上下两行的紧凑网速显示。

[下载与版本说明](https://github.com/nibaba999/AirStats-zh-CN/releases) · [MIT 许可证](LICENSE)

本版本仅支持 Apple 芯片、macOS 14 或更高版本。安装包采用临时签名，未经 Apple Developer ID 签名和公证，macOS 可能阻止打开。源码构建需要 Xcode 26 或更高版本。
