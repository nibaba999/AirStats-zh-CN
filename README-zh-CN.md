# AirStats 简体中文适配（开发中）

本项目基于 [AirStats](https://github.com/byrencheema/airstats) 修改，原作者为 Byren Cheema。上游版本：1.6，提交 `0609c85256c9d713d7333b90ea345cbf3560dff7`。这是非官方的简体中文适配，与原作者无隶属关系。

## 当前状态

已翻译主要监控面板、设置项目和常用状态。部分动态提示、帮助文字、可访问性文字以及系统或第三方组件仍为英文；这是进行中的汉化，并非完整翻译。

## 许可与归属

上游使用 MIT 许可证，原版权声明与许可条款保留在 [LICENSE](LICENSE)。本项目包含中文界面修改。第三方依赖 Sparkle 遵循其自身许可，详见其项目和发行包中的许可文件。AirStats 名称及图标属于上游项目，本仓库不声称官方身份。

## 构建

需要 Apple 芯片、macOS 14 或更高版本、Xcode 26 或更高版本，以及能够获取 Swift Package Manager 依赖的网络。使用 `Scripts/build.sh release` 构建。英文原版 README 中的 Homebrew 和官网下载方式安装的是上游英文版，不是本中文适配版。源码构建采用临时签名，不等同于官方签名及公证版本。此适配版使用独立应用标识和设置目录，默认不在登录时启动，关闭上游自动更新；请勿直接覆盖官方安装。
